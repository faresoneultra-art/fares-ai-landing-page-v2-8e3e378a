# تجربة أدوات AI المجانية

## افتح الموقع مباشرة
افتح START-HERE.html في Chrome أو Edge أو Firefox بعد تنزيله. كل الصور والفيديوهات والخطوط جوه نفس الملف، ومش محتاج إنترنت للعرض. روابط المواقع الخارجية بس هي اللي محتاجة اتصال.

لو تليجرام عرض الملف كنص أو معاينة، نزّله وافتحه بمتصفح عادي. مفيش تثبيت مطلوب.

## الموجود
- 50 عينة صور مرقمة حسب السجل النهائي، في قسم ثابت: كل صورة بتعدّي فوق اللي قبلها مع الاسكرول، وشرح وحدود كل تجربة جنبها.
- 25 فيديو، في قسم ثابت بيتبدّل مع الاسكرول، ومعاه أزرار وأرقام للاختيار.
- بحث في الصور، اختيارات أقوى، تكبير الصور، ومظهر فاتح وغامق.
- مكان واضح لرابط جروب الواتساب، لسه غير مفعّل لأن الرابط مش متوفر.

## الملفات
- START-HERE.html: النسخة المستقلة الجاهزة للفتح.
- site/: نسخة static جاهزة للرفع على استضافة.
- source/: مشروع React + Vite قابل للتعديل.

لتشغيل المصدر:
1. افتح source في Terminal.
2. npm install
3. npm run dev

للبناء: npm run build

## تعديل رابط الواتساب
في source/src/App.tsx، ابحث عن cta-panel واستبدل الزر غير المفعّل برابط الجروب. ابني النسخة من جديد بعد التعديل. تعديل المصدر مش بيغيّر START-HERE.html تلقائياً، لأنه نسخة مستقلة جاهزة.

## ملاحظات الدقة
دي لقطة اختبار بتاريخ 23 نوفمبر 2026، مش ضمان لاستمرار المجاني أو الحدود. الموديـلات مكتوبة حسب تسمية المواقع المستضيفة، ومش كلها متحققة من مصدر مستقل. بعض المواقع والموديـلات متكررة، فـ50 عينة مش 50 أداة مستقلة.

الصور والفيديوهات اللي اتبعتت للموقع نسخ خفيفة ومضغوطة للويب، مش الأصول كاملة الدقة. تقرير كل عينة بيحافظ على وصف الملف الأصلي وقت الاختبار؛ شريط مشغّل الفيديو بيعرض أبعاد ومدة النسخة الحالية. 25 فيديو من هدف 30، والطلبات الفاشلة أو المرفوضة مش محسوبة.

العينة 29 النهائية OmniGen 2، بدل FIBO المستبعدة. العينة 50 النهائية Flaq، بدل نتيجة Z-Image الضعيفة. تم استبعاد صور إضافية غير مرقمة وفيديو كرة قدم غير متعلق بالتجربة.

رابط ديمو العينة 20 الدقيق مش محفوظ بشكل كافي، فاتكتب ده بوضوح بدل تخمينه. بعض الصفحات ممكن تتغير أو تطلب تسجيل بعد تاريخ الاختبار. مراجعة شروط الاستخدام مطلوبة قبل النشر التجاري. المجاني في Magic Hour وFreeImageToVideo وImageVideoAI كان مقصور على الاستخدام الشخصي وقت الاختبار.
